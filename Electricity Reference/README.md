# Reference calculation: Electricity use in dissassembly
The following reference calculation is based on the disassembly of 1 m² of gypsum board using a cordless drill. The resulting electricity consumption per kg of material is used as an assumption across all EoL scenarios in the value creation catalogue where disassembly is performed using electric tools.

## Assumptions
Below is a list of all the assumptions made for the reference calculation.
- There are 20 screws per m² of gypsum board.
- Unscrewing one screw using a cordless drill takes 5 seconds.
- The cordless drill consumes 90 W of electricity when used.
- A gypsum board weighs 9.10 kg/m².

## Calculation
Based on the assumptions, the following can be calculated:
- Unscrewing one screw using the cordless drill requires 5 s/screw × 90 W = 450 J/screw of electricity.
- Unscrewing 1 m² of gypsum board using the cordless drill then requires 20 screws/m² × 450 J/screw = 9.00 kJ/m² of electricity.
- The disassembly of 1 kg of gypsum board using the cordless drill then requires 9.00 kJ/m² ÷ 9.10 kg/m² = 989 J/kg of electricity.
Thus, the assumption for disassembly using electric tools is that it requires **989 J of electricity per kg of material disassembled**.
